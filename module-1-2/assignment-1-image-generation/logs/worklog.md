### Техническая заметка

Первая попытка через OpenAI-совместимый эндпоинт `POST /api/v1/images/generations` с `size="1024x1024"` вернула HTTP 400 для Z-Image: «Модель tongyi-mai/z-image требует указать aspect_ratio». Этот эндпоинт не передаёт `aspect_ratio` для не-GPT моделей. Рабочее решение — единый **Media API** `POST /api/v1/media` с телом `{"model": ..., "input": {"prompt": ..., "aspect_ratio": "1:1", ...}}`. Неудачные запросы не тарифицировались (HTTP 400 до генерации).
