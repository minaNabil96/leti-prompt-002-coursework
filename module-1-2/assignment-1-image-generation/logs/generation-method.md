# Метод генерации

## Сервис

- **Polza.ai** — российский агрегатор AI-моделей, OpenAI-совместимый API: `https://polza.ai/api/v1`.
- Ключ: `pza_…` (действующий ключ проекта). Переменная окружения `POLZA_API_KEY` в оболочке отсутствовала; скрипт `scripts/generate.py` читает ключ из переменной, а при её отсутствии — из `../opencode.json` (конфигурация Polza-провайдера в рабочей папке). Ключ проверен запросом `GET /api/v1/models` → HTTP 200.
- Баланс на момент генерации: **345,26 ₽ доступно** (`GET /api/v1/balance`, 2026-11-05 18:57 UTC).

## Эндпоинт

Использован **Media API** `POST https://polza.ai/api/v1/media` — единый интерфейс Polza.ai для изображений, видео и аудио.

Почему не OpenAI-совместимый `/api/v1/images/generations`: для моделей Z-Image, Seedream и GPT-Image 1.5 этот эндпоинт требует параметр `aspect_ratio`, которого нет в схеме OpenAI Images API; запрос с `size="1024x1024"` возвращает HTTP 400 «Модель … требует указать aspect_ratio». Media API принимает `aspect_ratio` внутри объекта `input` и корректно работает со всеми четырьмя моделями.

## Тело запроса

```json
{
  "model": "<model_id>",
  "input": {
    "prompt": "<logs/prompt_en.txt, дословно>",
    "aspect_ratio": "1:1",
    "...": "параметры конкретной модели"
  }
}
```

Параметры по моделям:

| Модель | `input` |
| --- | --- |
| `google/gemini-2.5-flash-image` | `prompt`, `aspect_ratio: "1:1"` |
| `openai/gpt-image-1.5` | `prompt`, `aspect_ratio: "1:1"`, `quality: "medium"` (3 ₽; `high` стоил бы 16,5 ₽ и нарушил бы бюджет) |
| `tongyi-mai/z-image` | `prompt`, `aspect_ratio: "1:1"` |
| `bytedance/seedream-4` | `prompt`, `aspect_ratio: "1:1"`, `image_resolution: "1K"` |

Генерация синхронная; при статусе `pending` / `processing` скрипт опрашивает `GET /api/v1/media/{id}` каждые 3 секунды (таймаут 360 с).

## Замены моделей

Замен **не было**: все четыре ID из задания найдены в каталоге Polza.ai и успешно отработали. Архитектурные метки не менялись.

## Ограничения метода

- Одно изображение на модель, один промпт, без сидов и повторных прогонов — сравнение качественное, а не статистическое.
- Размер выхода у Seedream 4.0 (2048×2048) и GPT-Image 1.5 (1254×1254) отличается от запрошенного 1:1 1024×1024: провайдеры масштабируют выход, счёт остаётся по запрошенному тарифу (1K / medium).
- Оценка соответствия промпту выполнялась визуально по чек-листу из 13 бинарных пунктов; это неизбежно содержит элемент экспертной субъективности, поэтому все спорные наблюдения зафиксированы в `analysis.md` с указанием места артефакта.
