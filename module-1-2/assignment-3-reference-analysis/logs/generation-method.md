# Метод генерации изображений

## Модели

| Роль | Модель Polza.ai | Архитектура | Назначение |
| --- | --- | --- | --- |
| Мультимодальный аналитик и составитель промпта | `google/gemini-2.5-flash` | Трансформер (мультимодальный MoE) | анализ референса, составление подробного промпта |
| Генератор изображений | `bytedance/seedream-4` | Диффузия (rectified flow DiT, ByteDance Seedream 4.0) | обе генерации — по подробному и по наивному промпту |

Замен моделей не потребовалось: обе доступны в каталоге Polza.ai и вернули успешный результат.

## Единые условия для двух генераций

Чтобы сравнение было корректным, обе картинки созданы одним и тем же генератором при одинаковых
параметрах; единственное различие — текст промпта.

- Модель: `bytedance/seedream-4` — в обоих вызовах.
- Соотношение сторон: `1:1`, разрешение `1K`.
- Seed: `42` — передан в обоих вызовах; API принял параметр без ошибки (повторного вызова без seed
  не было).
- Фактический размер файлов на выходе: 2048×2048 px в обоих случаях (провайдер отдаёт результат в
  удвоенном разрешении при запросе 1K).
- API: Media API Polza.ai, `POST /api/v1/media` с телом
  `{"model": ..., "input": {"prompt": ..., "aspect_ratio": "1:1", "image_resolution": "1K", "seed": 42}}`
  и опросом `GET /api/v1/media/{id}` до статуса `completed`.

## Подготовка промптов

- Подробный промпт — ответ Gemini из шага 4. Из ответа убрана разговорная обёртка
  («Отличная задача! Вот промпт…», метка `**Prompt:**`) и markdown-разметка; сам английский текст
  промпта сохранён без изменений в `logs/prompt_used_detailed.txt`. Ответ модели в исходном виде
  остаётся в `logs/compose_call.json`.
- Наивный промпт — `A cat in the rain` (`logs/naive_prompt.txt`), без анализа стиля.
