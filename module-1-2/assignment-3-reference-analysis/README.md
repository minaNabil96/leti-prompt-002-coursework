# Задание 3: Референс → анализ → промпт

**Модуль:** 1–2
**Задание:** 3
**Тема:** Анализ стиля референса и генерация по подробному и наивному промпту
**Стоимость:** 6,29 ₽ из 15 ₽
**Статус:** Завершено

## Что сделано

В качестве референса взята картина Винсента Ван Гога «Звёздная ночь» (1889,
общественное достояние, Wikimedia Commons). Мультимодальная модель разобрала
палитру, свет и композицию, затем составила подробный промпт. Одна и та же
модель сгенерировала два изображения кота под дождём: по подробному промпту и
по наивному («кот под дождём в стиле Ван Гога»). Сравнение показывает, какие
признаки стиля удаётся передать словами, а какие теряются.

## Ключевые результаты

- Обе генерации выполнены одной моделью при одинаковых параметрах
  (1:1, 1K, seed 42); различался только текст промпта — сравнение корректное.
- Подробный промпт воспроизвёл кобальтово-синюю палитру, жёлтые акценты и
  контраст холодного и тёплого; наивный дал фотореалистичную серую сцену.
- Часть признаков не воспроизвелась и по подробному промпту: ночное небо,
  луна, звёзды с ореолами и закрученная композиция.
- Фактический размер обеих генераций — 2048×2048 px (провайдер удваивает 1K).
