# Правовой аспект использования MS COCO

## Структура лицензий

1. **Аннотации** (подписи, bounding boxes, сегментационные маски, keypoints) —
   **CC-BY 4.0** (Creative Commons Attribution 4.0). Это указано в условиях использования
   COCO (cocodataset.org/#termsofuse) и в теге лицензии карточки Hugging Face
   (`license: cc-by-4.0`).
2. **Изображения** — загружены с Flickr и сохраняют исходные лицензии Flickr. Команда COCO
   отбирала снимки с открытыми лицензиями; на практике это преимущественно **CC-BY** и
   **CC-BY-SA**, но конкретная лицензия зависит от исходной фотографии. При переиспользовании
   самих изображений нужно проверять лицензию каждого файла.
3. **Метаданные карточки** на Hugging Face распространяются по CC-BY 4.0 вместе с аннотациями.

## Что разрешено

- **Учебное использование — да.** CC-BY прямо разрешает использование в образовательных
  проектах, включая курсовые работы, при указании авторства.
- **Коммерческое использование — да.** CC-BY допускает коммерческое использование, в том
  числе создание продуктов на основе обученных моделей, при соблюдении атрибуции.
- **Изменение — да.** CC-BY и CC-BY-SA разрешают производные произведения.
- **Распространение — да.** Обе лицензии разрешают распространение при соблюдении условий.

## Требования

- **Атрибуция (BY).** Нужно указать датасет и авторов. Стандартная ссылка:
  «Microsoft COCO: Common Objects in Context. Lin et al., ECCV 2014. arXiv:1405.0312».
- **ShareAlike (SA) — только для изображений под CC-BY-SA.** Если распространяется
  изменённая версия такого изображения, производное нужно лицензировать под той же
  лицензией. Это относится к отдельным изображениям, а не к весам модели, обученной на них.
- **Проверка лицензии изображения.** Перед публикацией самих фотографий (а не только
  аннотаций) нужно убедиться, что конкретный файл распространяется под CC-BY, а не под
  более строгой лицензией.

## Можно ли использовать в учебном и коммерческом проекте

**Да, можно — и в учебном, и в коммерческом проекте**, если:

1. датасет процитирован (Lin et al., 2014);
2. соблюдены условия CC-BY 4.0 для аннотаций;
3. при распространении изображений проверены и соблюдены их индивидуальные лицензии;
4. для коммерческого продукта отдельно оценён юридический риск, связанный с тем, что
   правовой статус весов модели, обученной на чужих изображениях, в разных юрисдикциях
   трактуется неодинаково.

Последний пункт — «серая зона»: в большинстве трактовок веса модели не являются
производным произведением каждого обучающего изображения, но однозначного международного
решения нет. Для коммерческого запуска рекомендуется консультация юриста.

## Российский правовой контекст

Гражданский кодекс РФ (часть 4) признаёт открытые лицензии: статья 1286.1 регулирует
открытую лицензию на использование произведения науки, литературы или искусства.
Лицензии Creative Commons рассматриваются как допустимые условия использования
произведения. Таким образом, использование CC-BY данных в России правомерно при указании
автора и соблюдении условий лицензии.

## Вывод

MS COCO пригоден для курсовой работы и для коммерческих экспериментов с обучением моделей.
Обязательна атрибуция; при публикации самих фотографий — проверка индивидуальных лицензий
Flickr. Для коммерческого продукта с публикацией изображений или спорным использованием
весов нужна юридическая экспертиза.
