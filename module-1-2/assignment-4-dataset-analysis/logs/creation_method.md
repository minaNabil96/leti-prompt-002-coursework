# Способ создания датасета

## Классификация: смешанный

MS COCO относится к категории **«смешанный»** по классификации из лекций: сочетание
автоматического сбора данных и ручной разметки людьми.

### Автоматический компонент

Изображения не снимались специально для датасета. Они собраны с Flickr: авторы COCO
искали фотографии по 80 категориям объектов и их синонимам, а затем отбирали снимки,
где нужные объекты присутствуют в естественном контексте. Это автоматический сбор
данных из открытого фотохостинга, а не лабораторная съёмка.

### Ручной компонент

Разметка выполнена краудсорсингом на Amazon Mechanical Turk:

- **5 подписей на изображение** (image captioning) — разные исполнители описывают одну
  и ту же сцену, что даёт вариативность формулировок;
- **bounding boxes** — рамки объектов для 80 категорий (object detection);
- **segmentation masks** — попиксельные маски объектов (instance segmentation);
- **keypoints** — 17 ключевых точек для людей (pose estimation);
- **stuff-сегментация** — 91 класс фона (panoptic stuff).

### Почему это не чистая ручная разметка и не чистый автоматический сбор

Если бы датасет был только ручной разметкой, изображения тоже создавались бы или
отбирались людьми вручную. Если бы он был только автоматическим, подписи и маски
формировались бы алгоритмами без участия человека. В COCO оба этапа присутствуют:
**машина собирает фотографии, человек создаёт разметку**. Поэтому корректная категория —
«смешанный».

### Контроль качества

В публикации описан многоступенчатый контроль: квалификационные задания для исполнителей,
несколько исполнителей на одно изображение и согласование результатов (консенсус), а также
выборочная проверка аннотаций. Для неоднозначных случаев предусмотрена дополнительная
проверка; при этом отдельного института экспертной валидации для всех подписей в статье
не описано.
