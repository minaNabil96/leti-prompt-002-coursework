# Какие нейросети можно и нельзя обучать на MS COCO

## Можно обучить или дообучить

1. **Модель image captioning (BLIP, Show-and-Tell, Show-Attend-Tell).** В датасете пять
   независимых подписей на каждое изображение — это прямая обучающая пара «изображение →
   текст» для генерации описаний.
2. **Детектор объектов (YOLO, Faster R-CNN, DETR).** Для 80 категорий размечены bounding
   boxes; это стандартная супервизия для задачи object detection.
3. **Модель instance segmentation (Mask R-CNN).** Попиксельные маски объектов позволяют
   учить не только «что», но и «где именно» находится объект.
4. **Модель image-text matching / CLIP-подобная модель.** Пары «изображение — подпись»
   подходят для контрастивного обучения согласованию визуального и текстового
   пространств.
5. **Модель visual question answering (VQA).** Совместно с COCO-VQA (вопросы и ответы к
   изображениям COCO) датасет даёт супервизию для ответов на вопросы о сцене.

Дополнительно на COCO можно дообучать модели pose estimation (keypoints людей) и
panoptic segmentation (91 stuff-класс).

## Нельзя обучить или обучить качественно

1. **Текстовую языковую модель (GPT-подобную).** Подписи короткие — в среднем около
   десяти слов — и описывают только визуальную сцену. Корпуса связного текста на
   миллиарды слов здесь нет; для языкового моделирования нужен отдельный текстовый датасет.
2. **Аудиомодель (распознавание речи, синтез музыки).** В COCO нет ни аудиодорожек, ни
   транскриптов. Нужны LibriSpeech, Common Voice или аналогичные аудиодатасеты.
3. **Видеомодель (распознавание действий, генерация видео).** Изображения статичны, у них
   нет временного измерения. Нужны Kinetics, HowTo100M и другие видеонаборы.
4. **Генеративную модель изображений «с нуля» (Stable Diffusion и аналоги).** COCO можно
   использовать как небольшую часть обучающих пар, но 330 тыс. фотографий с ограниченной
   стилистикой недостаточно для сильной генеративной модели: LAION-5B содержит около
   5 млрд пар, то есть на четыре порядка больше. На одном COCO получится слабая модель.
5. **Модель генерации кода.** В датасете нет исходного кода и текстовых инструкций к нему;
   задача не соответствует содержимому.

## Связь с материалом курса

Это иллюстрация принципа «специфика задачи» (лекция 2.5): данные должны соответствовать
той задаче, для которой обучается модель. COCO силён в визуальном понимании — детекции,
сегментации, описании сцен, — но не заменяет текстовые, аудио-, видео- и кодовые корпуса.
