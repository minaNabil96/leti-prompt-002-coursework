## б) Гибридный сервис: Sber GigaChat + Kandinsky 3.1

- **GigaChat (трансформер):** понимает запрос на естественном языке, ведёт диалог, формирует текст
  и инструкции. Семейство GigaChat — русскоязычные LLM на трансформере с архитектурой MoE
  (arXiv:2506.09440 «GigaChat Family: Efficient Russian Language Modeling Through Mixture of Experts
  Architecture»).
- **Kandinsky 3.1 (диффузия):** генерирует изображение по текстовому описанию. Это «large-scale
  text-to-image generation model based on latent diffusion» (ai-forever.github.io/Kandinsky-3,
  технический отчёт Kandinsky 3, arXiv:2312.03511).
- **Как связаны:** в интерфейсе gigachat.ai GigaChat принимает и осмысляет запрос пользователя, а
  при запросе картинки переформулирует его в промпт для генерации и передаёт диффузионной модели
  Kandinsky, после чего возвращает готовое изображение в чат. Текст понимает одна архитектура,
  изображение синтезирует другая — это и есть связка «трансформер + диффузия» в одном продукте.

## в) Внешние признаки архитектуры без документации

1. **Тип входа/выхода.** Текстовые модели выдают последовательность токенов (текст → текст):
   T1–T3. Диффузионные модели выдают непрерывный массив пикселей, порождаемый из шума
   (шум → изображение): D1–D3.
2. **Характер времени генерации.** У диффузии время растёт с числом шагов денойзинга и разрешением
   (D3 при 2048×2048 — дольше, чем D1 при 1024×1024; D2 — 164 с). У трансформера время растёт с
   числом выходных токенов (T1 — 92 токена, T3 — 87 токенов).
3. **Характер ошибок.** У трансформеров ошибки смысловые и языковые (неточная формулировка,
   выдуманный факт). У диффузии — визуальные и пространственные (искажённые геометрия, мелкий
   текст, лишние пальцы).
4. **Вариативность при повторном запуске.** Диффузия с новым шумом даёт заметно другую картинку
   (высокая дисперсия). Трансформер при temperature = 0 почти детерминирован (низкая дисперсия).
5. **Текст внутри изображения.** Авторегрессионные трансформерные генераторы изображений рисуют
   читаемый текст, а классические диффузионные модели его часто «зашумляют». Это дополнительный
   признак в пользу трансформерного генератора изображений.
