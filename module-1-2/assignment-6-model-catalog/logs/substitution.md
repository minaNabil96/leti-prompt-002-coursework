# Замены и отступления от исходной формулировки

Задание 6 фиксирует шесть моделей и требует честно фиксировать любые замены.
Ниже перечислено всё, что в работе отличается от буквального ожидания, с
указанием причины и того, что реально сделано.

## 1. Замены моделей

**Замен нет.** Все шесть идентификаторов из задания существуют в каталоге
Hugging Face и доступны без токена:

| № | Идентификатор | HTTP при запросе `/api/models/{id}` |
| --- | --- | --- |
| M1 | `facebook/detr-resnet-50` | 200 |
| M2 | `dima806/facial_emotions_image_detection` | 200 |
| M3 | `facebook/musicgen-small` | 200 |
| M4 | `Salesforce/codegen-350M-mono` | 200 |
| M5 | `cardiffnlp/twitter-roberta-base-sentiment` | 200 |
| M6 | `d4data/biomedical-ner-all` | 200 |

## 2. Расхождения атрибутов карточек

В задании часть атрибутов приведена приблизительно. В отчёте указаны значения
из карточек и метаданных, а не из формулировки задания:

| Модель | Ожидалось | Фактически в карточке |
| --- | --- | --- |
| M2 `dima806/facial_emotions_image_detection` | лицензия MIT, 6 классов эмоций | лицензия `apache-2.0`; 7 классов: angry, disgust, fear, happy, neutral, sad, surprise; 85 804 039 параметров |
| M3 `facebook/musicgen-small` | «Small 300M» | 300 млн относится к языковой модели; в файлах весов 591 087 174 параметра (вместе с аудиокодеком) |
| M4 `Salesforce/codegen-350M-mono` | размер 350 млн | в карточке указано 350 млн; отдельного файла `safetensors` нет, веса в `pytorch_model.bin` |
| M5 `cardiffnlp/twitter-roberta-base-sentiment` | лицензия не оговорена | поле `license` отсутствует и в метаданных, и в README — в отчёте стоит «не указана» |

## 3. Способ выполнения демонстраций

Задание предполагает запуск демо на странице модели. Фактически онлайн-запуск
недоступен:

- `api-inference.huggingface.co` не разрешается в DNS из этой сети;
- `router.huggingface.co/hf-inference/models/...` отвечает **HTTP 401** без
  токена (`HF_TOKEN` не задан);
- виджет Inference API на странице модели требует входа в аккаунт.

Поэтому обе модели запущены **локально на тех же чекпоинтах** через
`transformers` 5.22.1 (CPU). Это не замена модели: скачаны те же веса, что и у
карточки. Входные данные настоящие, ответы сохранены в
`logs/demo_results/D1.json` и `D2.json`, скриншоты собраны по этим файлам.

## 4. Тестовое изображение для D1

Планировалось взять фотографию с Unsplash, но сервис недоступен из этой сети
(обрыв TLS, `curl (35) Recv failure`). Вместо него взято фото с Wikimedia
Commons: улица Амстердама с велосипедистами и грузовым велосипедом, автор Fons
Heijnsbroek, лицензия **CC0** (общественное достояние). Ссылка на файл и на
страницу указана в `D1.json`; лицензия CC0 не требует атрибуции, но автор
указан в подписи на скриншоте.
