# Анализ задания 6. Каталог моделей

## а) Две протестированные модели

### D1. Детекция объектов: `facebook/detr-resnet-50`

**Вход.** Реальное фото улицы Амстердама с велосипедистами, грузовым
велосипедом с детьми, пешеходами и автомобилями (Wikimedia Commons, лицензия
CC0, автор Fons Heijnsbroek, 2026). Размер 960×721 px.

**Что сделала модель.** Порог 0,90 оставил 28 обнаружений; при пороге 0,50 —
60. Уверенно найдены:

| Класс | Максимальная уверенность |
| --- | --- |
| person | 1,00 |
| car | 1,00 |
| bicycle | 1,00 |
| handbag | 0,97 |
| traffic light | 0,84 |
| backpack | 0,82 |

**Справилась ли с примером.** Да: все основные объекты сцены — люди,
велосипеды, машины, светофор — найдены с высокой уверенностью. Это ожидаемо:
сцена состоит из классов COCO, а датасет обучения (COCO 2017) как раз про
повседневные городские фотографии.

**Что ограничивает применение.**

1. Только 91 категория COCO. Логотипа бренда, конкретной модели автомобиля,
   элемента интерфейса или товара на полке в этом списке нет — модель их не
   найдёт, даже если человек видит объект.
2. Много дублирующих рамок. При пороге 0,90 дальние машины дают по 2–3
   пересекающихся box'а; без дополнительной фильтрации (NMS) результат трудно
   использовать в автоматическом подсчёте.
3. Мелкие объекты. Дальние пешеходы и автомобили занимают десятки пикселей:
   часть из них не детектируется, часть путается между классами car и person.
4. Скорость. DETR тяжелее YOLO: на CPU инференс занял 0,8 с на одном
   изображении, что для видеопотока в реальном времени мало.
5. Домены. Модель обучалась на естественных фотографиях; на рисунках,
   скриншотах и сгенерированных изображениях качество не гарантировано.

**Связь с лекциями.** Это типичные «краевые случаи» (лекция 2.4): сцена
рядовая, но объекты на границе кадра, вдали и в группе — именно там модель
ошибается. Ограничение по классам — иллюстрация «специализации инструмента»
(лекция 2.5): DETR решает одну задачу и не заменяет универсальную модель.

### D2. Анализ тональности: `cardiffnlp/twitter-roberta-base-sentiment`

**Вход.** Собственный текст: «I absolutely love the new AI course on prompt
engineering — it's incredibly useful and well-structured!» (108 символов,
английский).

**Выход.**

| Класс | Вероятность |
| --- | --- |
| negative | 0,15 % |
| neutral | 0,68 % |
| positive | 99,17 % |

**Справилась ли с примером.** Да, и с очень высокой уверенностью. Текст явно
положительный, модель это распознала; сумма вероятностей трёх классов равна
1,0000, то есть выход корректно нормирован.

**Что ограничивает применение.**

1. Только английский язык. Русские отзывы и комментарии анализировать нельзя
   без другой модели (например, multilingual XLM-T).
2. Домен Twitter. Модель дообучена на твитах: короткие фразы, сленг, эмодзи.
   На официальных пресс-релизах, научных текстах и длинных абзацах поведение
   может отличаться.
3. Три класса без нюансов. Сарказм, ирония и смешанная тональность
   («сервис отличный, но доставка ужасная») сводятся к одному усреднённому
   классу; уверенность при этом может оставаться высокой.
4. Нет опоры на контекст диалога. Каждое сообщение оценивается отдельно, без
   истории переписки.
5. Лицензия. В карточке модели лицензия не указана — для коммерческого
   проекта это юридический риск, который нужно закрывать отдельно.

**Связь с лекциями.** «Специфика задачи» (лекция 2.5): модель заточена под
короткий неформальный текст, и переносить её на деловую переписку без
дообучения (лекция 2.6) нельзя.

## б) Две модели для собственного мультимедиа-проекта

Проект: **система мониторинга медиаконтента для PR-службы** (сбор упоминаний
организации в соцсетях и медиа, автоматическая сортировка публикаций и раннее
выявление кризисных ситуаций).

1. **`facebook/detr-resnet-50`** — этап входного анализа изображений.
   Определяет людей, транспорт, товары и обстановку на фотографиях из
   публикаций, помогает автоматически раскладывать медиатеку по сюжетам и
   отбирать кадры для отчётов. Лицензия Apache 2.0 допускает коммерческое
   использование, 41,6 млн параметров позволяют запускать модель на одном
   сервере без GPU-кластера.
2. **`cardiffnlp/twitter-roberta-base-sentiment`** — этап анализа тональности
   текстовых упоминаний. Считает долю негативных сообщений, показывает всплески
   негатива и позволяет реагировать до того, как тема уйдёт в медиа. Модель
   лёгкая (около 125 млн параметров) и обучена именно на коротких сообщениях,
   то есть на том типе текста, который преобладает в соцсетях.

**Обоснование.** В PR-мониторинге два основных типа контента — изображения и
текст; выбранные модели закрывают оба и не дублируют друг друга. Обе
достаточно лёгкие для продакшена, а вместе образуют ядро конвейера
«собрать публикацию → разметить изображение → оценить тональность →
среагировать». Это прямое применение принципа «специализация инструментов»
(лекция 2.5): каждая модель делает одну задачу хорошо, а не пытается заменить
всю систему.

**Оговорка по лицензии.** У sentiment-модели лицензия в карточке не указана,
поэтому перед коммерческим запуском нужно либо получить разрешение авторов,
либо заменить её на модель, у которой лицензия явно указана в карточке.
