# Задание 6: Каталог моделей Hugging Face

**Модуль:** 1–2
**Задание:** 6
**Тема:** Каталог моделей Hugging Face: шесть карточек и две демонстрации
**Стоимость:** 0,00 ₽ (Hugging Face API без токена)
**Статус:** Завершено

## Что сделано

Собраны метаданные шести моделей Hugging Face по шести разным задачам,
проверена доступность карточек и заполненность README. Две модели запущены
на реальных входных данных: DETR (детекция объектов) и RoBERTa
(тональность). Поскольку Inference API без токена отвечает HTTP 401, обе
демонстрации выполнены локально на тех же чекпоинтах через `transformers`.
Собрано дерево задач и карточки моделей.

## Использованные модели

| Роль | Модель | Hugging Face ID |
|------|--------|-----------------|
| Детекция объектов | DETR ResNet-50 | `facebook/detr-resnet-50` |
| Классификация эмоций | ViT facial emotions | `dima806/facial_emotions_image_detection` |
| Генерация музыки | MusicGen Small | `facebook/musicgen-small` |
| Генерация кода | CodeGen 350M Mono | `Salesforce/codegen-350M-mono` |
| Тональность текста | Twitter RoBERTa | `cardiffnlp/twitter-roberta-base-sentiment` |
| NER в биомедицине | Biomedical NER | `d4data/biomedical-ner-all` |

## Ключевые результаты

- Все шесть карточек доступны без токена (HTTP 200), замен моделей нет.
- DETR при пороге 0,90 нашёл 28 объектов, при 0,50 — 60; уверенно
  распознаны person, car, bicycle (1,00), handbag (0,97).
- RoBERTa оценила положительный отзыв как positive с вероятностью 0,9917.
- Зафиксированы расхождения с формулировкой задания: у M2 лицензия
  Apache-2.0 и 7 классов эмоций (не MIT и 6), у M5 лицензия не указана.
- Демонстрации выполнены локально: `api-inference.huggingface.co` недоступен
  без токена, виджет требует входа в аккаунт.
