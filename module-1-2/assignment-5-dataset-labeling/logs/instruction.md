# Инструкция разметчика

**Задача:** классификация изображения на один из трёх классов: «афиша», «обложка книги», «постер фильма».

**Правило 1. АФИША (event poster).**
Признаки: содержит дату и/или время события; содержит название места (venue, адрес, зал); продвигает временное событие (концерт, выставка, лекция, спектакль, фестиваль). Иерархия текста: название события → дата → место.

**Правило 2. ОБЛОЖКА КНИГИ (book cover).**
Признаки: содержит имя автора; содержит название книги; нет даты события и нет названия места; часто присутствует логотип издательства; предназначена для физического продукта (книга).

**Правило 3. ПОСТЕР ФИЛЬМА (movie poster).**
Признаки: содержит название фильма; содержит блок титров в нижней части (credits block — мелкий текст со списком режиссёра, актёров, продюсеров); часто присутствует «coming soon» или дата релиза; драматичная визуальная композиция с персонажами.

**Правило 4. Признаки для различения.**
- Дата + место (venue) → АФИША
- Имя автора → ОБЛОЖКА КНИГИ
- Блок титров (credits) → ПОСТЕР ФИЛЬМА
- Логотип издательства → ОБЛОЖКА КНИГИ
- «Coming soon» / дата релиза без места → ПОСТЕР ФИЛЬМА

**Правило 5. Спорные случаи.**
Если изображение имеет признаки двух классов:
- Автор + драматичная иллюстрация (без credits block) → ОБЛОЖКА КНИГИ
- Дата + драматичная иллюстрация (без автора, без credits) → АФИША
- Credits block + название без автора → ПОСТЕР ФИЛЬМА

**Правило 6. Что делать со спорными случаями.**
Выберите ближайший класс по правилу 5 и обязательно отметьте сомнение в комментарии: «сомнение: [причина]».

**Правило 7. Вне категорий.**
Если изображение не является ни афишей, ни обложкой, ни постером фильма (например, пейзаж без текста) → отметьте «вне категорий» и поясните в комментарии.

---

*Все изображения в наборе — сгенерированные (Polza.ai, tongyi-mai/z-image), поэтому подписи и надписи на них могут быть искажены. Оценивайте тип носителя по композиции и набору текстовых блоков, а не по конкретным словам.*
