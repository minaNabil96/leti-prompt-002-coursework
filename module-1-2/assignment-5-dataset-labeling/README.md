# Задание 5: Разметка датасета для задачи классификации

**Модуль:** 1–2
**Задание:** 5
**Тема:** Разметка собственного датасета для классификации полиграфии
**Стоимость:** 34,26 ₽ из 50 ₽
**Статус:** Завершено

## Что сделано

Сгенерирован собственный датасет из 24 изображений трёх классов: афиша,
обложка книги, постер фильма (по 8 примеров на класс, 864×1152 px).
Составлена инструкция разметчика и таблица `разметка.xlsx`. Затем проведена
слепая разметка: модель `google/gemini-2.5-flash` получала только изображение
и инструкцию, без истинной метки и промпта. Совпадение с истинными метками —
100 % на основной выборке (10 из 10) и 100 % на стресс-тесте (8 из 8).
