## Что сделано

Проведена беседа из 12 реплик с `google/gemini-2.5-flash`: каждый следующий
запрос содержит системный промпт и всю историю диалога. Шесть ответов
синтезированы голосом Kore (`google/gemini-3.8-flash-lite-tts`), затем
распознаны `openai/whisper-large-v3` для самопроверки. Измерены темп, паузы,
основная частота и диапазон интонации; результаты сведены в отчёт.
