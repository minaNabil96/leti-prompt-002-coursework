ISO
639-1
two-letter codes (e.g.,
en
,
fr
,
de
).
Languages without an ISO 639-1 code use
ISO 639-3
three-letter codes: Asturian (
ast
), Cantonese (
yue
), Cebuano (
ceb
), and Filipino (
fil
).
