# М3-Задание 3: Оживление изображений — три анимации, три эффекта

**Модуль:** 3
**Задание:** 3
**Тема:** Image-to-video: три источника, три уровня интенсивности движения
**Стоимость:** 41,28 ₽ из 60 ₽
**Статус:** Завершено

## Что сделано

Подготовлены три источника: портрет и пейзаж сгенерированы `tongyi-mai/z-image`,
картина Ван Гога «Звёздная ночь» взята с Wikimedia Commons (общественное
достояние). Каждый источник анимирован моделью `bytedance/seedance-2-mini`
(image-to-video, 5 с, 480p) с разной интенсивностью движения — от лёгкого
поворота головы до выраженного движения кисти. Для каждой анимации измерены
покадровые различия и построены карты движения.

## Ключевые результаты

- Три ролика по 5,04 с, 24 кадра/с: 640×640, 864×496 и 752×560.
- Стоимость: 2 × 1,40 ₽ за источники + 3 × 12,825 ₽ за анимации = 41,275 ₽
  (68,8 % бюджета).
- Средняя покадровая разница: портрет 1,41, пейзаж 0,78, картина 4,03. Порядок
  не совпадает с заявленной интенсивностью: у пейзажа движение локальное
  (вода, облака), поэтому среднее по кадру ниже, а у картины меняется фактура
  по всему полотну.
- Аудиодорожки в роликах нет (`generate_audio: false`), звук не запрашивался.
- Замен модели не потребовалось: Seedance 2 Mini принял все три изображения.
