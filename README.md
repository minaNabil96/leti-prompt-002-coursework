## О репозитории

Репозиторий содержит все материалы курсовых работ по курсу «Применение
генеративных нейронных моделей в мультимедиа» (Prompt-002): отчёты,
сгенерированные изображения, видео, аудио, журналы API-вызовов, скриншоты,
промпты и скрипты. Материалы собраны для проверки преподавателями и
ассистентами курса фактических результатов: каждый файл можно открыть, а
каждое число — сверить с журналом.

В репозитории **10 заданий** из двух модулей: 543 файла, около 202 МБ.
Все медиафайлы включены напрямую; самый большой файл — 26 МБ, поэтому Git LFS
не требуется.

## Как проверить результаты

1. **Отчёты.** В каждой папке `report/` — файлы `.docx` и `.pdf` с одинаковым
   содержанием.
2. **Медиа.** Изображения — в `images/`, видео — в `animations/`, `scenes/`
   и `final/`, аудио — в `audio/`.
3. **Журналы.** В `logs/` — сырые JSON-ответы API, `cost.md` с построчной
   стоимостью и `worklog.md` с хронологией работ.
4. **Промпты.** В `prompts/` — все задания и антиошибочный чек-лист.
5. **Скрипты.** В `scripts/` — код, которым получены и собраны результаты.

## Воспроизводимость

1. Установить зависимости: `pip install openai pillow python-docx openpyxl requests pymupdf imageio-ffmpeg`.
2. Установить FFmpeg или использовать бинарник из `imageio-ffmpeg`.
3. Получить API-ключ Polza.ai: https://polza.ai → «API-ключи».
4. Задать переменную окружения `POLZA_API_KEY`.
5. Запустить нужный скрипт из `scripts/` соответствующего задания.

Ключи API в репозиторий не включены. Абсолютные пути к локальным папкам в
журналах заменены на `<WORKSPACE>` и `%USERPROFILE%`, чтобы не публиковать
данные рабочей машины.

## Особенности медиа

- Видео М3-3 и М3-4 сгенерированы в 480p и увеличены до итогового размера
  фильтрами FFmpeg; это апскейл, а не генерация в 1080p. Для М3-4 кадр
  увеличен до 1920×1080.
- В М3-2 сервис ElevenLabs недоступен из РФ, поэтому документация получена из
  архива официального сайта, а рисунки интерфейса — реконструкция по
  документации. Это прямо указано в отчёте и README задания.
- Отчёты описывают те же результаты, что лежат в `logs/`; расхождения, если
  они были, зафиксированы в журналах.
